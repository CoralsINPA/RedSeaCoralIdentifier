## Conclusions

**Portrait photos were mis-cropped by the legacy classification code.**
- 221 of 1,714 photos (13%) have a portrait frame (1920×2560).
- WC, V2, MA and the review-image cells all call `cv2.resize(image, (2560, 1920))`. For a portrait photo that squashes the image, and the mask is resized the same way. But the bbox stays in portrait coordinates, so the crop window misses the coral.
- Those corals were either dropped (empty or under 500 visible pixels) or classified from a partial, distorted cut-out.
- Affected:
  - legacy zero-shot labels (WC and V2) for portrait images;
  - the V2 count of 14,224 kept crops;
  - the Millepora audit PDFs;
  - probably some crops in Assaf's review.
- Hypothesis to check in Stage B: some of the 16 "unidentifiable" expert crops come from portrait images.
- **This corrects an earlier conclusion** (`2026-10-11_code_review_and_org_plan.md`) that the zero-shot path was already correct. It was correct only for landscape photos.
- The new code loads every photo in its JSON frame, so the new baseline fixes this for 13% of images. That's a real chance of better results.
- It also means Check C's expected 14,224 can't match. The correct parity test for Check C is landscape images only, kept keys compared with `v2_weak_labels_expanded.csv`.

**The expert CSV is the reference, not the memory matrix.**
- `assaf_expert_test_set.csv` has **77 rows**.
- Expert labels: 54 in the 20-genus set, 5 soft corals, and 18 with no genus.
- Accuracy: **36/54 = 66.7%** in-set (Wilson 95% 53.4-77.8%), and 36/59 = 61.0% counting the soft corals.
- Every matrix cell present in both agrees. The differences are whole rows:
  - the CSV lacks 1 correct Favia, 1 correct Favites, 1 correct Porites and 2 correct Stylophora;
  - it has 2 correct Seriatopora that the matrix lacks (probably the "2 likely Seriatopora missing from page 1").
- The evaluation code mapped all 18 rows with no expert genus to `missing`. It should read `is_correct` and split them into `unidentifiable` and `MISSING_LABEL`; 16 and 2 are expected, not yet confirmed. Accuracy is unaffected, because both statuses are excluded.
